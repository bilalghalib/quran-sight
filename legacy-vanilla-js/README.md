# Legacy Vanilla JavaScript Version

This folder contains the original vanilla JavaScript implementation of Quran Sight.

## Files

- **index.html** - Main HTML page with embedded UI controls
- **script.js** - Core visualization logic with canvas rendering
- **style.css** - Styles for the UI
- **animation.js** - Animation utilities
- **services.js** - Additional SVG export functionality
- **qurantext.py** - Python implementation using Cairo graphics
- **quranVisualexample.png** - Example visualization output
- **quran.txt** - Quranic text data

## Running the Legacy Version

To run this original version:

```bash
cd legacy-vanilla-js
python -m http.server 8000
```

Then visit http://localhost:8000

## Note

This is the original working version kept as a backup. The main project has been modernized to use Next.js, React, and TypeScript. See the root README for the current version.
